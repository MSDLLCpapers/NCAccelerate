Introduction
  • This app is designed for automating below items of FIH (first in human) SAD (single ascending dose) and MAD (multiple ascending dose) analysis:
    • Time-concentration plot
    • PK parameter summary table
    • Dose proportionality projection
Data
  • Designed for Ardena and Watson-styled data.
  • Please use the output time-concentration and PK parameter data (stacked) from the Phoenix NCA workflow. Names of the steps in the workflow:
    • Step 1a: Prep Sample Data_EXPORT for RShiny CvT Plot
      • If the output file is an excel file, please make sure the data has only one tab
    • Step 4a/c: EXPORT Results for RShiny PK Parameter Table
  • Acceptable data formats are .csv, .xlsx, .xls.
  • MAD time concentration data: for the purpose of the app, if period is not populated, it will be populated with 1.
  • Variables needed in input time-concentration data:
Variable Name* Variable Explanation Needed in Watson Data Needed in Ardena Data
PKEXTNAMcolumn value: “ARDENA”✓
PKEXTSUBJIDsubject ID✓✓
PKEXTORRESconcentration value✓✓
PKEXTNMHRnominal hour✓✓
PKEXTDOSE**dose value and unit✓✓
PKEXTSTUDYIDstudy ID✓✓
PKEXTSRCANLanalyte✓✓
PKEXTSPECABmatrix✓✓
PKEXTPKSEQpanel✓✓
PKEXTPERIODperiod✓✓
PKEXTSTDYDYday✓✓
  • * Column names of the input data should be the same as Variable Name (e.g., Column name “Period” won’t work, it has to be “PKEXTPERIOD”).
  • ** Ardena data format should be value followed by unit (e.g., 50 mg), no second row in column header. Watson data format should be value only (e.g., 50), with unit (e.g., mg) in the second row of column header.
Layout
  • The "Data Check", "Mean Concentration Data", "Time-Concentration Plot" tabs are used for time-concentration data.
  • The "PK Parameter Table" and "Dose Proportionality" tabs are used for PK parameter data (stacked).
